## Basic attacks — all classes

Every friendly class gets Strike when unarmed or using a melee weapon. A ranged weapon replaces it with Shoot. These basic attacks have no class-level requirement and occupy the first ability slot.

## Updating this reference

With the Class Ability Reference editor plugin enabled, saved changes refresh this file after a short delay. External edits refresh when Godot detects them; changes made while Godot is closed refresh when the project next opens. Unsaved Inspector edits are excluded.

To refresh manually, use **Project → Tools → Regenerate Class Abilities**. From the project directory:

```text
godot --headless --path . --script res://addons/class_ability_reference/generate_reference.gd
godot --headless --path . --script res://addons/class_ability_reference/generate_reference.gd -- --check
```

The second command checks for missing or outdated content without writing it. See [class authoring and progression](docs/character_classes.md) for editing instructions.
