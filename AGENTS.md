# Project instructions

These instructions apply to all Codex tasks working in this repository.

## Commit and push after every modification

- After every completed modification, run relevant checks, commit the task's changes, and push the current branch to `origin` before reporting completion.
- A completed modification means a coherent change, including documentation and configuration edits.
- The user has given standing authorization for routine commits and pushes. Do not ask for confirmation again.
- Set upstream tracking when needed with `git push --set-upstream origin <current-branch>`.
- Include only the task's changes in the commit; preserve unrelated work.
- Report commit or push failures clearly. Never force-push without explicit user authorization.
